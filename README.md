# Excel-data-cleaning-transformation
Excel-based data cleaning and transformation project demonstrating missing-value handling, data standardization, duplicate removal, data splitting and merging, formatting, and conditional analysis.

## Project Overview

This project is part of the *Program in AI-Driven Data Analytics Course*. The assignment focuses on cleaning and transforming a product dataset using Microsoft Excel.

The dataset was cleaned by handling missing values, correcting inconsistent data, removing duplicates, splitting Product IDs, merging columns, and applying appropriate formatting and conditional formatting.

### Key Excel Functions & Tools Used

- `PROPER()` – Standardize text capitalization
- `MEDIAN()` – Impute missing price values
- `FILTER()` – Filter category-specific data
- `DATE()` / `DATEVALUE()` – Create and format dates
- `&` – Merge text from multiple columns
- *Find & Replace* – Correct inconsistent values
- *Remove Duplicates* – Remove duplicate records
- *Text to Columns* – Split Product ID
- *Conditional Formatting* – Highlight and visualize data

### Result

The original dataset contained *34 records*. After removing *3 duplicate records* and addressing missing and inconsistent data, the final cleaned dataset contains *31 unique records *.*

The completed Excel workbook contains the original data, cleaned dataset, analysis results, formulas, and step-by-step documentation.
